# Historical capture and review tools

These scripts and uncommitted patches preserve the historical capture, depth conversion, quality checks, and archive disposition implementation. They are archived source, not a current deployment or reproduction guarantee. Several disposition scripts intentionally delete precisely selected local recordings; their original approval and hash gates are preserved. No script was executed as part of this source publication. Historical paths, dependency assumptions, and missing adjacent evidence may require reconstruction before a runnable experiment is possible.

Two copies of the historical upload helper replace only the operator-specific Windows home-directory component with `ARCHIVE_USER`. Secret names and calls remain references to external credential stores; no credential values are included. The original source hashes and public-copy hashes are recorded in the manifest. Scientific values, validation thresholds, original failure conditions, and the byte contents of all other sources are retained.
