# Public data and research catalog

Browse the released Diogenes archives below or start with the [demo website](https://diogenesmodel.com). Source code is in this GitHub repository; recorded data and research weights are hosted by [DiogenesLab on Hugging Face](https://huggingface.co/DiogenesLab). Hosted collection and training services have ended.

Each dataset card describes its scope, historical limitations and permitted use. The Apache-2.0 source-code license does not apply to gameplay recordings, datasets, game assets, third-party components or model weights. Historical `non_trainable`, QC, rights and certification fields remain unchanged. Public access does not establish production-training eligibility.

RAW, converted clips, camera/depth experiments and research derivatives can overlap. Do not add their file counts or sizes together as independent capture hours. Failed and incomplete artifacts are retained as evidence where their dataset cards say so.

## Verify and resolve an archived file

Start with the collection README. Many collections include `MANIFEST.jsonl` for logical members and `ARCHIVE_INDEX.jsonl` for TAR shards; some use a specialized member index documented in their card. Follow the recorded repository, immutable revision, archive and member path, then compare the public byte length and SHA-256. A historical source-container hash does not identify a normalized or privacy-corrected replacement.

For the multigame tables, use `legacy/tabular-sample/MEDIA_INDEX.jsonl`: the original Parquet media paths and hashes describe historical originals, while this index identifies current public files, including explicit privacy copies. Old private distributions are retired. Private originals and unreleased restricted material are not included in this public catalog.
